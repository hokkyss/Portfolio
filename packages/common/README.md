# @portfolio/common

Common utilities and shared code for the Portfolio monorepo.

## Overview

This package contains shared business logic, base types, and general errors used across applications and packages.

### Exports

- `logger`: Structured logging utilities.
- `types`: Shared TypeScript definitions and domain models.
- `errors/application-error`: Base application error class for consistent error handling.

## Dependencies

- [`zod`](https://zod.dev/): TypeScript-first schema validation.
- [`ts-pattern`](https://github.com/gvergnaud/ts-pattern): Pattern matching in TypeScript.

## Installation

```bash
pnpm add @portfolio/common
```
