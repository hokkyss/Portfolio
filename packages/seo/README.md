# @portfolio/seo

SEO utilities and configuration for the Portfolio monorepo.

## Overview

This package contains helpers and generators for managing Search Engine Optimization (SEO) aspects of the applications.

### Exports

- `metadata`: Helpers for generating page metadata.
- `robots`: Generators for `robots.txt` configuration.
- `sitemap`: Utilities for creating XML sitemaps.
- `opengraph`: OpenGraph metadata builders.
- `twitter`: Twitter card metadata builders.
- `app-links`: App link specifications.
- `icons`, `manifest`, `viewport`: Asset and viewport configurations.

## Installation

```bash
pnpm add @portfolio/seo
```
