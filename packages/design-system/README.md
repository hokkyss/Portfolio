# @portfolio/design-system

Shared UI components, theme providers, and design system for the Portfolio monorepo.

## Overview

This package is built with React, Tailwind CSS, and Radix UI primitives (shadcn). It provides a comprehensive set of accessible, highly-customizable UI components.

### Key Features and Exports

- **Layout & Structure**: `sidebar`, `scroll-area`, `separator`, `table`, `card`
- **Forms & Inputs**: `input`, `textarea`, `select`, `switch`, `toggle`, `field`, `label`
- **Navigation & Menus**: `dropdown-menu`, `navigation-menu`, `accordion`
- **Feedback & Overlays**: `alert`, `toast`, `tooltip`, `badge`
- **Typography & Theme**: `application-theme-provider`
- **Utilities**: `cn` and `tw` for class merging and Tailwind utility composition.

## Installation

```bash
pnpm add @portfolio/design-system
```
